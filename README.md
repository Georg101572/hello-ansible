## Цель работы

Освоить базовые принципы работы с Ansible: настройку SSH-доступа, управление хостами, выполнение ad-hoc команд и создание playbook.

---

## Этап 1. Установка Ansible

На управляющей машине была выполнена установка Python и Ansible.  
Проверена корректность установки командой `ansible --version`.

---

## Этап 2. Настройка SSH-доступа

Сгенерирована SSH-ключевая пара и настроена аутентификация без пароля для пользователя `ansible`.  
Подключение к управляемому хосту по SSH прошло успешно.
